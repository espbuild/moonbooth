# Security policy

## Reporting a vulnerability

Email moonbooth@erikp.com with a description of the issue and the steps to
reproduce it. Please do not open a public issue for a vulnerability.

## What to expect

We will acknowledge your report and work on a fix. Moonbooth does not run a
bug bounty program and does not pay for reports.

## Product security posture

How the Moonbooth product handles credentials, package storage, and related
matters is documented at https://www.moonbooth.ai/security.
